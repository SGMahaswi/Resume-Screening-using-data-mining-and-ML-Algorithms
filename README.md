# Resume Screening using Data Mining and Machine Learning Algorithms

## 📌 Project Overview
This project implements an intelligent **Resume Screening System** using **Data Mining and Machine Learning techniques**.  
The system automatically analyzes resumes, extracts key features, and classifies candidates based on their suitability for specific job roles.  
It helps reduce manual screening effort and enables data-driven hiring decisions.

---

## 🎯 Objectives
- Automate the resume screening process  
- Extract meaningful features from resumes  
- Apply machine learning algorithms for classification  
- Rank candidates based on relevance  
- Improve recruitment efficiency and accuracy  

---

## 🧠 Technologies Used
- **Programming Language:** Python  
- **Machine Learning:** Scikit-learn  
- **Data Processing:** Pandas, NumPy  
- **Data Mining Techniques:**  
  - Data preprocessing  
  - Feature extraction  
  - Pattern recognition  
- **Visualization:** Matplotlib, Seaborn  
- **Dataset:** Resume data stored in CSV format

## ⚙️ System Workflow
1. Load the resume dataset  
2. Perform text preprocessing  
3. Extract key features such as skills and experience  
4. Train machine learning models  
5. Classify resumes into job categories  
6. Rank candidates based on model predictions
